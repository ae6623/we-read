# 本地PDF角色可迁移规则记忆

- 角色轨迹仅显示一次性本地试读历史并入 Windows读书；不据此推断当前Agent启用。
- 本地PDF无微信读书书内AI时，四项AI问书须标“AI自主整理 · 非微信读书返回”，依据限于获授权、已核实材料。
- OCR/定位不确定须明示；引文要逐字核对并落在实际已读范围内。
- 同队活动锁、main登记、管理员本场转达及实时状态核对同样适用；本地文件可见不等于授权。
