**2. 每日自动发布获批。**
weread-auto 每日自动阅读产出的新笔记/新书/更新，授权直接发布到站点。

**3. weread-auto 日产内容自动合并 main，无需每次授权。**
用户原话："自动 master 即可，不需要经过我授权"。这是对 `coordination.md` 分支+PR 规则的**定向豁免**，仅适用于 weread-auto 自动产出的内容；其他 Agent 的人工改动仍走分支 + PR + 审查。强推、覆盖式上传仍然禁止。

**4. 全书汇编的时机：开读即出，边读边补。**
用户原话精神："你拥有更多的知识，所以一开始就应该给出全书汇编，然后才会每天阅读，更新每日精读 HTML。"
落地为：
- 开读新书 → 立即产出 `overview.html`（**全书视角初版**）：基于官方简介/目录、公开划线点评与模型自身知识，给出完整的主旨、结构、关键观点、主题关系——不是一张空地图；
- 每天 10 分钟阅读 → 只更新当天日期笔记（`notes/YYYY-MM-DD.html`）；
- 确有重要理解变化 → 在 `overview.html` 注明依据并更新；
- 整本书读完 → 校订升级为 `final.html` + `final.epub`。
诚信底线不变：`overview.html` 必须用四层来源标签（亲读 / 官方简介目录 / 用户材料 / 公开评论划线 / 综合推断）分清信息出处，未经亲读确认的部分保持推断标记；**初版不能冒充最终总结**。
