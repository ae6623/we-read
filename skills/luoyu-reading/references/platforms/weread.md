# 微信读书平台适配

本文件只说明微信读书来源与访问边界；整书预读、每日笔记和完读汇编仍按 `SKILL.md` 的共用流程执行。后续接入其他阅读平台时，为该平台新增独立适配文件，不把平台特有步骤写进共用流程。

## 开始前核验

- 根据当前可访问的书籍页面核对书名、作者及版本；信息不一致时先暂停并向用户确认，不把同名书或不同版本混为一谈。
- 先检查该书已有的预读框架、日期笔记和最终汇编，并按 `references/coordination.md` 的规则核对共享归档与并行修改状态。
- 微信读书页面或应用是否可用取决于当前执行环境和用户已授权的访问方式。只使用当前环境实际提供、且已获授权的功能；不要假定某种页面、控件、导出能力或自动化接口必然存在。

## 微信读书官方 Skill（辅助，不替代阅读器）

- 官方 [WeChatReading Skill](https://github.com/Tencent/WeChatReading) 可用于书籍搜索、书架、书籍详情、目录、阅读进度、个人笔记／划线、书评与阅读统计；Cue 的 Skills 由用户账号共享，导入一次后可供其 Agent 使用。未确认用户已完成导入时，不声称各 Agent 已安装。
- 能力仅以官方当前 Skill 文档／接口目录为准；目前没有正文读取或调用微信读书书内 AI 问答的接口。可用 Skill 减少查书、目录和进度等重复浏览器预检，但实际正文范围、阅读器位置及书内 AI 问答仍须通过获授权的阅读器操作确认。
- API Key 是敏感凭据。只从当前执行环境可安全调用的已保存秘密读取，不索取重复表单、不写进仓库／日志／聊天，也不传给浏览器子任务或其他 Agent。若当前环境无法安全取得 Key 或接口不可用，直接使用既有获授权浏览器流程，不让它阻塞排班。
- API 返回的目录、进度、划线、想法或统计只按其真实来源标注，不等于本场亲读或 AI 问答；查询 API 本身不算阅读，不计阅读窗口或平台有效阅读时长。读书状态、正文覆盖和完读仍按共享协议与本书适用流程记录。

### 建议混合流程

1. **预检减负**：在可用时先用官方 Skill 搜书并核对书名、作者、详情、目录和已有进度；返回的章节层级与字数可帮助选篇幅流程。先按 registry 核认领、活动锁与责任，再以官方 reader link 或当前获授权阅读器确认本场实际打开的是同一书目／版本。
2. **锁与通知不变**：开始登记被最新 main 接受并收到本场“已转达”后，才打开阅读器；不得因为Skill已查到目录或进度而提前开读。
3. **正文与书内AI仍用阅读器**：在授权阅读器核对真实续读屏、实际读正文，并在本书AI对话完成获准问答；遇到缺项、截断或自相矛盾，可从不同角度多轮追问，等上一答完整返回再继续。官方 Skill 的元数据和划线不能代替正文阅读、实际阅读范围或书内AI答复。出现反自动化／验证提示立即停止；同一操作障碍约5–6次无进展也停止并报告，不绕过。
4. **收尾按来源分开**：必要时用Skill查个人划线／想法或最新进度作补充，标为接口数据；亲读范围、理解窗口、平台有效时长和续读点仍按本场可见证据记录，不用累计数据倒推本场时长。API暂不可用时，只要获授权阅读器可正常继续，就回到原浏览器流程，不为配置Skill拖延或错过场次。

## 阅读证据

- 只把实际打开并阅读到的内容作为本次亲读依据。简介、目录、书评、公开划线和平台显示的阅读进度分别标注来源，不能替代亲读。
- 记录章节、页码或进度时，以用户提供的记录或平台当前明确显示的信息为准；无法核实的范围标为未知，不推测、不补造。
- 只有在用户确认全书已读完，或有明确且可靠的完成证据并经用户确认后，才制作最终整书汇编。

## AI 问书：通读全书全貌时必做

- 按 [AI 问书规范](../ai-ask-book.md) 核对本书后实际打开 AI 对话，在输入框一次提交 `书籍亮点+背景解读+关键概念+10个最佳金句语录`；不再要求逐个点击固定按钮。等待并读取完整最终答复，分别整理「书籍亮点」「背景解读」「关键概念」「10个最佳金句语录」。
- 记录实际合并提示词、来源、获取时间与四项各自核验状态；不把深度思考过程当答案，不把一次提交或一项回答冒充四项均已取得，不把 AI 输出当亲读事实。入口或某项不可用如实标待补；若补充自主整理，明确标「AI 自主整理 · 非微信读书返回」，不能伪称已提交或已取得。
- 平台推荐的金句仅为候选：只收可访问、可逐字核验且属于已读范围的短原文，每条标真实出处与核验结果。能核对几条就写几条；没有则说明，无须凑十条，不从未读文本补引文，遵守全页累计版权短引限制。
- 此操作须避开其他 Agent 的活动阅读器，不打断或改变他人阅读位置；不绕过登录、付费或访问限制，不将问答时间冒充平台有效阅读时长。截图仅是用户示例，控件可用性仍须现场核验。

## 访问与隐私边界

- 不猜测、索取或保存账户密码、验证码等凭据；不绕过登录、会员付费、访问控制、版权保护或平台限制。
- 遇到登录、付费墙、内容不可见、权限不足或操作结果不确定时，说明实际阻碍并暂停受限动作；不声称已阅读、打卡、标记或导出成功。
- 默认只在私下归档和聊天中交付，不在微信读书内发布想法或笔记。公开发布阅读材料前，遵循用户对具体内容的明确授权及共享归档规则。
- 引用原书内容保持必要且简短；不复制整书、长章节或大段受版权保护文本。
