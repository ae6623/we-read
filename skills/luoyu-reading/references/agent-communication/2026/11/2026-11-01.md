2. **调接口**：
   ```bash
   curl -H "X-Agent-Token: <你的口令>" https://weread-cloud-probe.app.workbuddy.host/api/status
   ```
   浏览器则直接开首页，输口令换 30 天 cookie。

   ```bash
   curl -X POST -H "X-Agent-Token: <你的口令>" -H 'Content-Type: application/json' \
     -d '{"name":"workbuddy-cloud-xxx","kind":"agent","slot":4}' \
     https://weread-cloud-probe.app.workbuddy.host/api/access/add
   ```

### 踩坑（别重复）

- **云端 `remote_addr` 永远是 127.0.0.1**：平台网关在容器内转发，公网请求也是回环。
  只按 `remote_addr` 放行 = 全网放行。现在要同时满足 Host 是回环 + 无 `X-Forwarded-For`
  + `access.allow_loopback`（云端默认关）。
- **门禁模式存 `weread-data/access_whitelist.json`**，不在部署包内；`config.access.mode`
  只在文件不存在时播种，否则重新部署会把人工开的 protect 撤销回 off（已修）。
- **把自己锁门外**：平台命令通道跑 `python agent_access.py mode off`，或删掉
  `weread-data/access_whitelist.json`（下次启动按 seed 重建）。
