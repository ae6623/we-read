# 管理员核查清单

此清单仅供受授权的协调、审查和状态核查；它不是实时状态源，也不授权写入或阅读正文。

1. **定位与基线**：确认同一授权仓库身份，读取最新远端 `main`，记录 commit；取不到或无法证明仓库相同即停止。只从该 main 加载相关 `luoyu-reading` 最新规范。
2. **权限**：对实际执行环境逐项核实仓库、文件范围、Git 写入和 Pages 权限；不继承任何会话浏览器登录、Skill、其他 Agent 权限或历史成功。不得查看、传播或写入秘密。
3. **状态**：从 registry 核验书目 owner、claim、`active_sessions`（兼容旧锁 `active_session`）、`resume_point`；roster 只作排班／身份／状态镜像。核对 `reading-state:` main commit 与同一 `run_id`，再查实际日期日文件。区分计划、开始、完成、发布、在线验证和通知。
4. **锁与转交**：按书目、environment_id、resource_ids 判断冲突，独立环境不同书可并行，共享浏览器仍互斥；旧锁未安全收尾或相关写入端未确认接入，不启用并行。Windows 本地阅读自主管理，不套用浏览器转达门槛。不超时自动抢锁。owner 未明确释放或无法确认运行已停即阻塞；转交需用户明确授权且核清锁责任。不代认领，不以派活转 owner。
5. **排班／恢复**：按最新 main 的决定和实际记录检查，不复制静态名单／时段。中断后确认已停、基线及授权；不自动续跑、不补跑、不重置，不绕过用量、验证或权限限制。
6. **内容审查**：只审获授权的公开笔记与归档卡，不打开书籍正文或私人材料。确认归档卡有书介、实质分析和精读输入；移除后台流水账与冗余免责；保留来源、事实缺口、亲读/AI状态。长书 AI 输入覆盖官方目录全章问答，输出主线、章节分析、跨章综合与可精读问题；分析按证据灵活组织，不机械模板、不跳章，不冒充亲读/时长，不回改旧阅读事实。
7. **UI 与隐私**：共享 UI 只使用同一 main 的唯一 `archive-ui.md`。不复制规范、不借审查改他人内容。私有场次、分析稿、秘密、聊天摘录和私人绝对路径不得进 Git、Pages、索引。
8. **Git／Pages**：确认授权文件范围；审阅状态、差异、`git diff --check`；保留他人增量，不强推、不越权合并。部署后在线核验；未核验不称已发布，未确认送达不称已通知，未核对安装状态不称已安装。
9. **报告**：说明实际证据、未完成项、不确定项与阻塞；权限不足时仅交付无秘密补丁给获批通道。填好的交接仅经获授权私下传递。
