25四 假设审查法：把“理所当然”拎出来晒 未读›

30三 极端假设法，暂时改变一个变量 未读›
  1. 极端假设法是暂时设定一个很大的、很小的或接近零的取值，观察原有关系如何变化。
  2. 极端假设法的操作步骤包括：选一个可能影响结果的变量，并说明为什么选它；设定一个便于思考的极端情形，推演会发生什么，也留意哪些原有条件随之失效；

  2. 先画出目前的资金流：谁付钱，为什么付，获得什么，履约需要哪些支出

51二 拆开“主动投资能跑赢市场”这个信念 未读›
  1. 选择主动管理，至少涉及三件事：是否有人具备取得超额收益的能力；自己能否事先识别合适的管理者；扣除全部费用后，取得的回报是否仍与承担的风险相称。
  2. 先讨论整体层面的算术关系
  3. 之后才比较费用
  4. 这类论证通常称为主动管理的算术关系
52三 从追求胜出转向控制成本 未读›
  1. 主动基金在这些项目上作出主动判断，指数基金则主要依据既定指数规则构建组合
  2. 减少主动选择，按明确规则持有目标组合，并控制实施成本
  3. 把注意力移到较容易核对的部分：持仓范围、费用和执行方式
  4. 第一项检查是比较对象：讨论整体算术关系时，市场范围和资金权重要一致。
53四 消费决策的陷阱：研究本身也是成本 未读›
  1. 为了作选择，自己花了多少时间
  2. 继续研究是否值得，取决于它还有多大可能改变选择，而非已经看了多少资料
  3. 如果两个候选项都满足必要条件，新的比较又只重复已知差别，就可以考虑停止搜索
  4. 不能假定同价位商品都差不多
54五 把决策成本算进去 未读›
  1. 投资和消费都提醒我们把决策成本算进去
  2. 不能靠“努力总有回报”或“努力没有用”两句话概括
  3. 下一次准备继续研究时，可以问：我还缺哪条会改变决定的信息？
  4. 理解一个关系，与设计产品、控制费用、建立运营能力，之间仍隔着大量专业工作。
55一 记住了结论，不等于理解了原理 未读›
  1. 一个人能熟练说出术语，却未必知道它对应什么现象
  2. 这里缺少的，可能是定义与观察之间的联系，也可能是不清楚公式的适用条件
  3. 父亲带他观察鸟的经历，让他理解知道名称和认识事物的区别
  4. 费曼学习法是后来整理的学习步骤，并非费曼亲自命名的一套标准程序
56二 “学会了”的真正标准是什么 未读›
  1. “学会”需要具体的目标，如能复述内容、解答新题、完成操作，还是向别人说明。
  2. 检验必须贴近学习目标，概念需要理解和应用，动作技能还需要实际表现
  3. 讲解是理解的一项证据，还应与解题、操作或资料核对等方式配合
57三 把讲解放进学习过程 未读›
  1. 讲解可以暴露空白，不必等到觉得全学会后才开始使用它
  2. 重点不是表演讲得流畅，而是找到下一步具体该学什么
  3. 讲解和做题各有盲区，没有必要把前者说成必然比后者严格
  4. 对方没听明白时，先确认卡在哪里
58四 按学习目标选择检验方式 未读›
  1. 概念、原理和方案的逻辑适合用讲解检查
  2. 可以按目标选择输出形式
  3. 听者也不必一律是毫无基础的外行
  4. 找不到听者时，也可以写说明、录音或做应用题，再对照材料
59五 读完一章后尝试说明 未读›
  1. 合上书，试着说明这一章解决了什么问题、核心理由是什么
  2. 阅读时，例子和上下文会不断提示我们。合上书以后，需要自己恢复这些连接，难度自然不同
  3. 先明确自己需要完成哪些任务，再学习相应流程
  4. 理解流程以后，遇到新情形更容易判断该查哪部分资料
60六 让理解留下可检查的证据 未读›
  1. 保留区分熟悉和理解的感受，有助于安排下一步学习。
  2. 合上材料再说一遍，是制造检查机会的一种简单办法
  3. 记录具体错误以后，复习便有了方向
  4. 学习这一章尤其提醒我们，自己的判断也要接受检查
61一 概括词不能代替分析 未读›
  1. 用一个概括词替代了需要调查的关系
  2. 需要更具体的理由来取消或保留打卡制度
  3. 换一个角度描述问题
  4. 逆向思考
62二 不要停在未经验证的解释上 未读›
  1. 拆解问题并非越深越好，要判断后续分析能否改变决策
  2. “一次性使用”也不是第一性原理，它是一种可以调整的方案特征
  3. 日常讨论里，同样要防止给一个可能原因过早盖章
  4. 何时停下，可以用一个务实标准判断：现有分析是否足以设计下一项有区分力的检查或小试验
63三 原理是起点，不是终点 未读›
  1. 把想清方向当成已经完成工作是错误的
  2. 一个“可以”的判断背后，往往还有很长的验证过程
  3. 在每次分析最后写一项下一步动作，让判断有机会接触现实。
64四 分析投入也需要取舍 未读›
  1. 严密拆解需要资料和时间，重要领域还需要专业积累。
  2. 熟悉、低代价的小选择，可以用经验快速处理。
  3. 选一个基本需求明确的小工具，比较功能并试用，往往已经足够。
  4. 只有现有工具持续不能满足关键需求时，才值得进一步拆解工作方式。
65五 避免把方法变成固定规定 未读›
  1. 任何方法都可能被机械使用，第一性原理也需要接受“眼前是否值得用”的检查。
  2. 讨论方案时，反复追问“你的第一性原理是什么”，未必能推进工作
  3. 如果要求每个选择都从头证明，方法就可能增加负担
  4. 判断问题需要哪一种证据，比忠于某个方法名称重要。
66六 给方法保留修正的余地 未读›
  1. 检查关键前提是否核实，拆解是否影响决策，下一步怎样执行，以及投入是否值得。
  2. 若方法让问题越来越含糊，也应停下来调整
  3. 知道这些边界不能保证不出错，但能帮助及早发现：问题在信息、推理、执行，还是方法选择。
  4. 练习的目标，是逐渐分得清这些差别。
67一 从知道方法到实际使用 未读›
  1. 知道操作步骤与能在现场使用，之间还隔着练习
  2. 思考方法也需要接触真实任务，才能得到反馈
  3. 依赖熟悉办法比较省力，完整拆解则要额外投入注意和时间
  4. 许多日常事情用现成经验便能处理好，应当把更细的分析留给值得投入的问题
68二 让关键问题更容易被想起来 未读›
  1. 本能是对熟练习惯的比喻，并非生理学意义上的先天本能。
  2. 熟练不等于可以放弃警觉
  3. 记住几个有用的提示，并能在需要时调用
  4. 专家常能较快识别熟悉领域的模式，但这种熟练依赖长期接触与反馈
69三 四种可以尝试的练习 未读›
  1. 每周挑一个范围较小、确实困扰你的问题
  2. 重点是让分析走到验证，而非必须用完所有工具
  3. 留意“应该”“大家都”“一般”等词
  4. 只把关键前提标出来，写上“已核实”“待查”或“个人偏好”，也能减少混淆
70四 观察练习带来的变化 未读›
  1. 面对重要方案时，你会更愿意写出它依赖什么条件，而不是只比较哪一种说法更动听。
  2. 也更容易决定分析到哪里为止：小事用经验，关键缺口继续查证。
  3. 听到“用户至上”“效率优先”，可以追问具体含义。
  4. 把一句口号转成可讨论、可观察的问题，比换成另一句更抽象的话更有用。
71五 从一件可控的小事开始 未读›
  1. 读者无需一次记住全部名称，可以把书中的方法当作检查提示，需要时翻回来核对，不必按章背诵。
  2. 更值得留下的是一份自己的记录：原来怎样判断，依据是什么，试过以后发生了什么。
  3. 合上书后，选一件可控的小事，把事实和猜测分开，提出一个可执行的改动，并写下什么时候检查效果。
  4. 第一次可能遗漏很多，发现遗漏后补进去，再试一次即可。练习不会按次数保证进步，但每次认真核对，都能留下下一次可用的材料。
72二 重构四法（第5章） 未读›
  1. 连续追问法→约束反推法。
  2. 成本要素拆解法→极端假设法。
  3. 假设审查法→要素重组法。
  4. 类比消除法→验证回路法。
