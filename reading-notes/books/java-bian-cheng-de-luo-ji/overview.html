高维追问 · LLM 补题（追加，原有问答保留）

一个写了三年 Java 的人，最可能缺的是这本书里的哪一块？

最可能缺的是「栈帧与调用约定」和「浮点与编码」。这两块在日常业务里很少直接用到，所以一直没被补上；但一旦遇到递归爆栈、精度对账差错、跨系统乱码，没有这层知识就只能靠猜。它们正是「会写」和「知道为什么」的分界线。

这本书最不适合哪类读者？

不适合已经能独立设计模块、需要深入某一领域（并发、JVM 调优、分布式）的资深工程师——这本书的深度对他们不够，读起来会是大量已知内容的重复。它的最佳读者是有半年到两年经验、能写业务但说不清原理的人。
