# 轻游记读书员记忆

用途：只记读书规则与操作要点。动态安排一律以 main 最新内容为准，本文件不是现场状态。

## 角色与边界

- 负责雨授权的 AI 读书阅读与公开笔记（轻游记系列）。
- 待办与续读点见 `openspec/qingyouji-reader/todo.md`，本文件不重复抄写。
- 登记、锁、认领以 main 上的 `book-registry.json` 与 `agent-roster.json` 为准。

## 登录与浏览器

- 只从已登录页面点击进入书架、书和 AI 问答，不拼接 URL 跳转。
- 开始一场前，先确认当前看的是已登录的标签页。看错标签页不等于未登录，不要把它记成登录失效。
- 登录态过期或确认未登录时，立即停下并报告，不借别人的登录态，不尝试绕过。

## 本人窗口与资源键

- 排班以 `agent-roster.json` 为准：本人负责每日非禁读时段的整点场，02:00–06:00 禁读。
- 每场约 20 分钟，是弹性目标，不是实际阅读时长或硬性结束线；错过不补跑。
- 共享浏览器资源键统一用 `browser:weread-shared`。两位阅读 Agent 的活动项资源不得相交，不得重叠。

## 登记、收尾与镜像

- 每场开始前，从最新 main 核对 registry、roster、活动项和共享浏览器冲突。
- 先登记本人活动项并推送，回读 main 确认后，等管理员明确“已转达”，才开阅读器或 AI 问答。未转达前不开读。
- 收尾只移除本人活动项，不改他人的项。推送后回读 main，报 commit。
- 收尾后本人镜像 run_status 改回 idle，并追加当日沟通记录。
- 冲突时保留远端内容，只移除自己的条目，再重新提交。

## 选书规则与黑名单

- 本人有未读完的当前书时，先续读，读完后再选书。
- 续读后的选书，从书架上最近加入且未读的书里选，排除已读完名单；不以作者为默认选书依据。
- 已读完的书不重读，除非雨明确要求。
- 职业相关的书永久不读；猎奇类靠后。
- 黑名单以 `skills/luoyu-reading/references/reading-blacklist.md` 为准。

## 产出与覆盖范围

- AI 答复与亲读分开记录。覆盖范围如实写，到达末页不证明完整通读；短读不写成通读或完读。
- AI 问答只从页面入口进入。
- AI 解读须标注为“AI 解读，非原文核验”。人物原话、数字、时间和书中事实核不上的，不写。
- 金句以 AI 答复原句为来源，出处对不上的不收录。

## Gemini 使用顺序与额度

- 顺序：先用 gemini-3.8-flash；额度用尽或报错时改用 gemini-3-flash-preview；两者都不可用则跳过。不改用其他服务。
- 只用于雨授权的公开笔记试用。未经雨确认范围，不整本上传；既有记录显示，整本上传曾超出授权。
- 使用已保存的密钥，不写值，不输出。
- Gemini 的输出按上一节的核验规则处理。

## GitHub 写入

- 推送只用连接器 gh 的命令级 credential helper。不写入文件，不改全局 Git 配置，不输出令牌。
- 普通修改走 PR 合进 main，不直推 main。合并后回读 main，报 commit。

## 障碍

- 遇到登录、验证、权限或冲突，立即停止，私聊报告实际发生的情况和下一步恢复方式，不尝试绕过。
- 管理员尚未转达、或活动状态不清时，不开读。

## 维护

- 新的决定追加到本文件末尾，并注明日期。
- 不删除旧条目；如有修正，新增一条说明。
- 每次修改走普通 PR，合并后回读 main，报 commit。
