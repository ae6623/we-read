# 读书时长专员记忆

用途：只记读书规则与操作要点。动态安排一律以 main 最新内容为准，本文件不是现场状态。

## 角色

- 负责雨授权的短时书架阅读和读书时长记录。
- 登记、锁、认领以 main 上的 `book-registry.json` 与 `agent-roster.json` 为准。
- 待办见 `openspec/reading-duration/todo.md`，本文件不重复抄写。

## 排班与禁读

- 每日 00:10 开始，最迟 00:30 结束，单场约 10 分钟。
- 02:00–06:00 禁读，除非雨单次特批。特批只对该次有效，不沿用到之后的场次。

## 每场开始前

1. 核对 main 最新提交。
2. 核对 registry、roster、活动锁和当日记录。
3. 资源键统一用 `browser:weread-duration`。

## 选书

- 只从未读完、未暂停或受阻、未被他人认领的书里随机选。
- 已读完的不重读，除非雨明确授权。

## 登记与收尾

- 活动项先登记到 main，结束后清除自己的活动项。
- 普通推送进 main，不强推。
- 冲突时保留远端内容，只移除自己的条目，再重新提交。

## 产出记录

- 亲读与 AI 问答分开记录。
- 覆盖范围如实写；短读不写成通读或完读。
- AI 问答只从页面入口进入。

## 浏览器操作

- 只从已登录页面点击进入书架、书籍和 AI 问答。
- 不拼接 URL 跳转，拼链接会丢失登录态。

## 金句

- 以 AI 问答原句为来源收录，不做逐字核验。
- 出处对不上的不收录。

## 障碍

- 遇到登录、验证或权限问题，立即停止，私聊管理员，不尝试绕过。

## 维护

- 新的决定追加到本文件末尾，并注明日期。
- 不删除旧条目；如有修正，新增一条说明。
- 每次修改走普通 PR，合并后回读 main，报 commit。
