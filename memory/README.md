# 读书成员记忆目录（memory）

用途：每位读书成员保存一份精简的工作记忆，只记读书规则与操作要点，帮助下次开工时不再犯同样的错。

## 结构

- `memory/<成员>/memory.md`：该成员自己的记忆文件，只由本人维护。
- 管理员的团队级记忆放在 `memory/admin/memory.md`。

## 允许写入

1. 登录与浏览器：只从已登录页面点进书架、书和问答，不拼 URL；登录态过期时停下来报告，不借别人的登录态。
2. 本人的排班窗口、禁读时段、资源键（如 `browser:weread-shared`、`browser:weread-duration`、`local_pdf:xpdf-reader`）。
3. 登记、收尾、镜像的流程：先从最新 main 登记，再开读；收尾移除自己的活动项，镜像改 idle。
4. 选书规则与黑名单：职业相关永久不读；猎奇靠后；已读完的不重读。
5. 本人当前续读点与待办，指向 `todo/` 或 `openspec/` 中的对应文件，不重复抄写。
6. 公开表述：用“AI读书”，不写平台原名；不写 Agent UID、群 ID。

## 禁止写入

- 账号、密码、token、设备码、API key 或 secret 的值（只能写引用名）。
- 个人联系方式、私人路径、用户本机文件位置。
- 他人的登录态、他人的待办或他人的记录。
- 原始 AI 答复或书籍正文的长段摘录。

## 维护

- 每次有新的用户决定，追加到本人的记忆文件末尾，并注明日期。
- 不删除旧条目；如有修正，新增一条说明。
- 每次修改走普通 PR，合并后回读 main，报 commit。
