# 天涯 PDF 库 EPUB 化与忽略清单（2026-11-07）

## 口径

- **不设字数上限**：EPUB 每 40 页（或 30,000 字）切一个 XHTML 章节，
  在线阅读器一次只渲染当前章节，正文再长也不会把 DOM 撑爆。
- **按文件大小设限**：生成后的 `.epub` 超过 **15 MB**（15,728,640 字节）则跳过，不上传 Pages。
  依据是浏览器要先把整个 epub 读进内存交给 JSZip 解压，单文件过大首屏会明显变慢（手机更明显）。
- 无有效文本层（疑似扫描件）或提取失败的同样跳过，不属于大小问题。
- 单页 HTML 全文页仍按 30 万字上限生成，两套产物互不替代。
- 本机 PDF 库两个子文件夹按编号前缀去重，同编号多版本优先「完整版」。

## 入口

- EPUB 书架：`reading-notes/epub/index.html`（集合页最底部「入口」两字直达）。
- 在线阅读器：`reading-notes/epub/reader.html?book=<id>`。
- 单页全文索引与每个 `fulltext.html` 顶部均有 EPUB 入口；集合页各抽屉也有。
- 阅读引擎 `epub.js` / `JSZip` 已本地化到 `reading-notes/epub/vendor/`，运行时零外链。

## 边界

- EPUB 需通过 HTTP(S) 打开（浏览器 `file://` 下 fetch 二进制会被 CORS 拦）；
  线上 Pages 可直接用，本机可用任意静态服务器，或把 `.epub` 下载后用 Readest / Calibre 读。
- 页面在公开 Pages 上，`noindex` / 不进导航 / 不外链只减少扩散，不等于私有。
- 不改既有笔记结论、覆盖标记与用户亲读状态。
