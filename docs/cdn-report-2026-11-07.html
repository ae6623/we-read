五、风险与回滚

  • 费用 七牛 HTTPS 流量不计入免费额度，按量计费；图片 + 字体量级下约每月几元。
  • 证书 免费证书 90 天，到期 2027-02-05；首页已挂提前 7 天条幅提醒。
  • 依赖 页面渲染现在依赖 CDN 可用；CDN 故障时 CSS/JS 会加载失败（字体有兜底，CSS/JS 没有）。
  • 回滚：python scripts/cdn_all_assets.py --revert，或 git checkout pre-cdn-2026-11-07。
