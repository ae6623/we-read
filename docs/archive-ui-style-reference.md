# 阅读归档 UI 样式参考

## 先看到书，再按需打开入口

同一本书的导览、全书视角、日期笔记和下载不再用圆点横向平铺。书目标题、来源标签、阅读范围与未完读说明保持可见；附属链接放入一个默认收起的「阅读入口」小抽屉。点击后纵向显示 1、2、3……，项目增多时自然向下延展，不裁切、不横向滚动。

这份文档只规定归档界面，不定义角色名称、职责、排班、书目归属或任务分发。那些信息由独立治理文档维护。

## 使用范围

- 首页和按书归档的书目卡片：附属链接统一使用抽屉。单入口也保持同款结构，未来增加链接不需要换布局。
- 系列页中的单本书目卡片：固定导览、全书视角、日期笔记放在同一抽屉；不折叠整本书的简介或阅读状态。
- 全书视角和旧书页的「相关日期笔记」：使用同款抽屉，标题可用「日期笔记」。
- 主导航、分类页签、系列主题索引、正文中的来源链接、上一篇／下一篇、返回链接、既有章节目录抽屉不在此次迁移范围。它们用途不同，不为了视觉一致而混改。

## 组件契约

引用 `assets/css/book-link-drawer.css`，用原生 `<details class="book-link-drawer">` 和 `<summary>`，不添加 `open`。不依赖 JavaScript，也不将链接放进 summary；点标题展开，点子项才跳转。

summary 左侧为「阅读入口」，旁边为真实的「N 项」，右侧为随展开状态变化的箭头。展开体用 `<ol class="book-link-list">`，每个 `<li>` 里放一个 `.drawer-item`；编号由列表顺序生成，从 1 开始，连续增长，不是章节号或官方册序。每项保留一个真实目标链接及原有 `download` 属性；必要的「未完读」说明放在该项 `.drawer-note` 中。

排序优先沿用已有顺序，避免此次样式迁移改变阅读含义。新列表建议固定导览 → 全书视角 → 日期笔记 → 完读汇编／下载；日期笔记依实际日期排列并保持稳定。不得因为展示需要预建尚不存在的日期笔记、完读页或 EPUB。

只有固定导览、尚无亲读笔记时，显示「1 项」，打开后保留导览链接与 `.drawer-empty` 说明。不制造空链接，不把「0 篇亲读笔记」写成「0 个入口」。完全没有真实链接时只用简短空状态，不显示可点击的空抽屉。

组件片段见 `templates/book-link-drawer.html`。生成器和其他编辑者新增同类区块时复用此结构，不复制一份私有 CSS。

## 视觉与手机排版

沿用站点纸色、墨绿、鼠尾草绿和赭金，不另建风格。边框使用 `--line`，圆角 12px；summary 至少 48px 高，每个链接至少 44px 点击高度。抽屉内边距 14px；窄屏降为 12px。编号列宽 26px，正文列使用 `minmax(0,1fr)`，长题名自然换行。

不设置固定展开高度，不用省略号隐藏关键标题，不依赖悬停。焦点有 3px 可见描边；原生 summary 支持 Tab、Enter 和空格。无动画，避免切换闪烁和额外运动负担。颜色只辅助区分，未完读等重要状态必须同时有文字。

## 发布验收

运行 `python3 scripts/check-book-link-drawers.py` 和 `git diff --check`。检查手机 320／390 CSS px 与桌面 1280px：默认收起、键盘可展开、编号连续、长标题不溢出；展开前后全部原有链接与下载属性不丢失。

新增笔记只更新相应列表和真实计数，不回写书籍观点、阅读时长、完读事实或私人记录。本规范只约束界面，不以本地预览代替线上发布验收。
