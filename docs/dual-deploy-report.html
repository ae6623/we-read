六、发布流程（必须遵守）

  • python scripts/stage_pages.py 生成 _site/（289 MB / 3,787 文件）
  • 把 _site/ 全量传到七牛 we-read-assets，保持相对路径
  • 传完必须刷新 CDN 缓存：CdnManager.refresh_dirs(['https://cdn.js-dev.cn/'])
    七牛默认缓存 30 天，不刷新会一直看到旧页面（这一轮就踩过）

七、风险

  • 缓存 每次发布后要手动刷缓存，否则改动不生效。
  • 计费 七牛 HTTPS 流量不计入免费额度，按量计费。
  • 证书 免费证书 90 天，2027-02-05 到期；首页已挂提前 7 天条幅 + 定时任务提醒。
  • 一致 两套入口靠「相对路径 + CDN 资源」维持一致，新页面违反约束会导致其中一套 404。

八、回滚

  • 整站回到 CDN 之前：git checkout pre-cdn-2026-11-07
  • 仅撤销资源引用：python scripts/cdn_all_assets.py --revert
  • CDN 完全不可用时：只用 ae6623.github.io/we-read/，页面仍可打开
