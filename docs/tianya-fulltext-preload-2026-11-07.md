# 天涯 PDF 原文预置与忽略清单（2026-11-07）

## 背景

阅读 Agent 的笔记短时间做不完，因此不等笔记，直接从本机 PDF 库按标题编号
预置全文阅读页。页面与集合页笔记配套的全文页用同一套阅读器，
左侧书架由 `reading-notes/books/bookshelf.json` 自动扫描汇总，新书入目录无需逐个改页面。

## 抽样口径

- 本机 PDF 库两个子文件夹共 210 个 PDF；按编号前缀去重、排除已有笔记与已有全文页占用的 16 个编号后，剩 188 个候选。
- 固定随机种子 `20261107`，从候选中随机抽 50 本。
- 同一编号有多个版本时优先「完整版」，否则取体积最大的一份。
- 正文超过 **200,000 字**（用户口径 20 万字）的本批一律忽略，不生成网页、不上传。
- 无有效文本层（每页平均不足 30 字，疑似扫描件）或无法提取正文的同样忽略。
- 页码与字数均为本机 PDF 文本层逐页提取结果，未经 OCR、未上传正文。

## 边界

- 只新增全文页、索引页、书架清单与入口链接；不改既有笔记结论、覆盖标记与亲读状态。
- 阅读页均为公开 Pages 上的静态页，`noindex` / 不进导航 / 不外链只减少扩散，不等于私有。
- 预置页没有配套阅读笔记，不写进集合页的 16 本条目列表，避免与笔记一一对应关系混淆。
