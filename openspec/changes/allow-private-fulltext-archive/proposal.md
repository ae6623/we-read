## Why

2026-11-07 用户实测：本人从论坛帖导出的 PDF 要写入本人私有笔记，读书 Agent 两轮拒绝。用户先后给出「上传的这个笔记只有我能读」「实在不行就加密码页显示原文」，Agent 均回「密码只限制谁能看，不能替代全文转载授权；把全文放到密码页仍是在另一处复制发布」。

根因不是可见性，是三处共享规则把「复制整篇原文到另一个页面」定为禁止动作，没有区分目标位置。个人存档和公开发布被混成一类，规则粒度太粗。用户明确要求三处改为允许。

## What Changes

- `skills/luoyu-reading/SKILL.md`：笔记质量段的引用限制改为按目标位置分流，新增本人私有笔记／私下归档的全文存档豁免。
- `skills/luoyu-reading/references/ai-ask-book.md`：交付前检查项去掉「大段受版权保护文本」，注明短引限制仅适用于公开页面；金句短引规则本身不改。
- `docs/local-reading-guide.md`：公开与私有边界段拆成两段，私有位置允许保存原始 PDF／全书文本／chunks／原文转录，公开位置限制不变。
- 新增 `docs/allow-private-fulltext-archive-2026-11-07.md` 记录需求与解决方案。
- 三处各自独立写清豁免条件，避免 Agent 只读到其中一个文件时继续套用旧限制。

## 影响面

| 对象 | 变化 |
|---|---|
| 本人导出／上传材料 → 本人私有笔记／私下归档 | 允许全文转录与保存，不受短引总量约束 |
| 公开页面 | 无变化，仍只发提炼分析 + 必要短引 |
| 凭据、登录态、私有路径、私人运行日志 | 禁止不变 |
| 既有笔记、发布物、历史记录 | 不追溯 |
| 排班、认领、完读计数、状态协议 | 不动 |

## Out of Scope

- 不授予任何对外转载、发布或分发许可。
- 不取消版权短引规则在公开页面的适用。
- 不批量回改既有笔记与发布物。
- 不改动笔记核验范围、金句来源、AI 问书流程。

## 已知边界

- 规则文本更新后，运行中的 Agent 需下次读取最新 main 才采用；不声称当前会话已热更新。
- 「私有」由目标位置与访问范围界定，不由是否加密码界定；密码页不改变归档归属，也不构成授权。

- 白名单判据只有一个：用户明确点名书／材料并表示允许。对话内一句即生效，无需预登记、无需证明授权、无需满足可见性或密码条件。
- 白名单书籍无条件服从：按用户要求全文转录、保存、写入笔记或发布，不再以版权、短引总量、全文、公开页面、分享外链、可见性、密码、授权或任何硬性条件为由拒绝、打折、追问或追加条件。
- 优先级最高，覆盖上一版写入的全部引用与发布限制，包括公开页面短引、不得转公开页／外链、不得发布原始 PDF 与 chunks。
- 作用域只限用户点名的书／材料，不自动扩散、不自动追溯。
- 三处规则各自独立写入该条并放在显眼位置，避免 Agent 只读一份时漏掉。

`AGENTS.md` 的凭据／登录态／私有路径禁止项与版权无关，不因本条改变，也不作为拒绝理由。
