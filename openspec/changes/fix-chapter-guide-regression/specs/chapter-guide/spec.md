# 章节导读（chapter-guide）规范

## 意图

站内每一本有通读页的书，都必须在通读页上有一个**可展开的章节导读**：章号、章名、每章的小节与逐字原句。精读页的章节树与它同构、同源、同样式。

「页面上只有一串章名，点不开任何东西」不满足本规范。

## 要求

### R1 数据装配单一入口

章节 → 小节 → 要点 → 原句的装配 MUST 只在一个函数里完成（当前为 `produce_all.chapter_blocks()`）。通读页与精读页 MUST 消费同一份输出，不得各自遍历一遍章节列表。

### R2 没有的就不写

- 某章一条原始素材都没有 → 该章 MUST 退化为**一行静态章名**（`<div class="mmx-cn mmx-cn-empty">`）：不做成可展开的折叠（点开是空白），也 MUST NOT 显示「0 条」「共 0 个小节 · 0 条要点 · 0 句原句摘录」。一排 0 会让读者以为页面坏了。
- 全书一条热门划线都没有 → 页面 MUST 在章节树上方给一句说明（「本书暂无公开热门划线，章节树只到目录层级」），把「没数据」和「加载失败」区分开。
- 数据源没有「章的功能定位」「本章一句话概括」→ 这两个字段 MUST 为空，渲染器 MUST NOT 输出空 span/空段落占位。

### R3 章名派生不得使用模板文案

章名是纯序号（`一`、`第二章`、`12`）或为空时，按「首小节名 → 首要点 → 锚点原句 → 第N章」派生。派生链上 MUST 跳过生成器自己造的通用文案（`本节要点`、`读者划得最多的句子`、`划线 12128 人` 等），否则会出现整本书每章同名。

### R4 一行原文只出现一次

要点行与引文行 MUST NOT 重复同一句话。当前口径：要点行写「划线 N 人」，原句放引文块。

### R5 样式只引用共享组件

章节树样式 MUST 来自 `assets/css/mmx-guide.css`（全部 `mmx-` 前缀），页面 MUST NOT 内联第二套章节样式。新增样式一律以 `mmx-` 前缀追加到该文件。

### R6 入口必须可达

任何在仓库里存在 `reading-notes/books/<slug>/overview.html` 或 `mindmap.html` 的书，首页对应的卡片墙上 MUST 有对应卡片。新增书的生产流程 MUST 在产出后调用挂卡（`link_index.py`），且该操作 MUST 幂等。

### R7 单章书用书名当章名

清洗后只剩一章、且该章标题是 `正文` / `全文` / `内容` 这类占位名时，章名 MUST 用书名顶上（去掉《》与副标题括注）。多章书的「正文」不动。

### R8 产出前置条件

生产流程产出精读页 MUST 同时满足：①清洗后有效章 ≥ 1；②该书热门划线 ≥ 1。任一条不满足 MUST 跳过产出，而不是写一个没有内容来源的空壳页。

> 历史背景：旧判据是「有效章 ≥ 2」，把「轻游记」这类清洗后只剩一章的单篇书整本挡在门外，页面因此长期停在老空壳上。

## 场景

```
场景：新书产出
  给定 书架里有一本未产出的书
  当   生产流程跑完
  那么 通读页含「章节导读」，章数与平台目录一致
  并且 每章展开显示热门划线原句，无划线章显示 0 小节
  并且 首页书架墙与精读墙各出现一张卡，链到对应页面

场景：存量简版回填
  给定 线上存在 < 20KB 的通读页（无章节导读）
  当   跑 rebuild_overview.py
  那么 该页重建为含章节导读的版本，其他文件不变
  并且 若线上页面比本地更充实，保留线上（安全阀拦截）

场景：章名为纯序号的书
  给定 《大明王朝1566》目录只有「第一章」「第二章」
  当   渲染章节导读
  那么 章名显示「第2章」而不是「读者划得最多的句子」
```
