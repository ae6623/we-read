# we-read：阅读笔记归档

一个无需构建工具的静态阅读笔记站点，可直接通过 GitHub Pages 发布。主页提供轻量搜索，笔记与整书汇编使用分开的目录和模板。

## 目录结构

- `index.html`：主页与归档索引
- `assets/css/site.css`：共享响应式样式
- `assets/js/site.js`：主页搜索筛选
- `notes/YYYY/`：按年份存放日期笔记
- `books/<slug>/`：按书目存放整书汇编与 EPUB
- `templates/`：日期笔记与整书汇编模板
- `.github/workflows/pages.yml`：GitHub Pages 自动发布

## 更换 Cue 账号后重建读书团队

从 [团队导入说明](skills/TEAM-IMPORT.md) 开始：含一句话启动口令、管理员及四类读书员的独立 Skill、精简共享工作记忆与安全交接流程。它是可迁移的角色与规则包，不复制私人聊天、凭据或原账号权限，也不会自动开读、抢锁或恢复暂停任务。

## 使用方式

复制 `templates/reading-note.html` 创建日期笔记，按实际阅读范围填写；整本书完成后再用 `templates/book-collection.html` 制作主题汇编。此类面向用户的AI读书阅读笔记已获持续公开授权，今后默认公开，无需逐篇再次确认；内部协调、原始场次与活动运行元数据以及跨书综合仍保持私有，其他内容按各自授权范围处理。

## 当前示例

- 按书目与日期保留阅读笔记，含《世界这么大，我想到处躺》2026-10-17 与 2026-10-18 两篇独立日期笔记
- 《挪威极夜：独处时才能成为自己（轻游记）》的 HTML 主题汇编及 EPUB

站点由 `main` 分支根目录通过 GitHub Pages 发布。

## 阅读员与实读指标

首页每张阅读内容卡（日期笔记、全书视角、汇编）标注阅读员名称和 Agent 类型，依据登记、提交和通信记录确认；无法确认时写“未知 / 待确认”，不凭文风猜测。归档模板说明卡不标阅读员；多人参与时列出各阅读员及类型。搜索可直接搜索“浏览器 Agent”或“代码 Agent”。

日期笔记沿用 `templates/reading-note.html` 或共享 Skill 的 `templates/date-note.html`，后续新阅读填写阅读员、实际时长及计时口径、真实章节/帖子/小节标题、实际覆盖范围、有依据的全书进度与平台有效阅读时长；不以页码/页数导航或作醒目笔记维度，不编造标题或定位。旧书、已发布笔记与历史记录不回改。站点模板同时引用 `assets/css/reading-metrics.css`；Skill 模板自带样式。平台未显示则写“未显示 / 未知 / 未确认”，不得编造百分比、把翻页当页数、把浏览窗口当有效阅读时长，或用未知值绘制进度条。同日多场或多人合并须逐场保留归属和指标口径，不混加不同计时类型。
